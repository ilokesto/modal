# Modal

`@ilokesto/modal`은 React 애플리케이션을 위한 완성형 모달 계층입니다. `@ilokesto/overlay`를 기반으로 대화상자 렌더링, 포커스 관리, Escape 키와 백드롭을 통한 닫기, 스크롤 잠금, 스택, 모션, 타입이 지정된 비동기 결과를 제공합니다.

## 가장 짧은 실용 예제

```tsx lineNumbers
import { ModalProvider, useModal } from '@ilokesto/modal';

function DeleteButton() {
  const { display } = useModal();

  async function confirmDelete() {
    const confirmed = await display<boolean>({
      ariaLabelledBy: 'delete-title',
      render: (close) => (
        <section style={{ padding: 24, background: 'white', borderRadius: 12 }}>
          <h2 id="delete-title">프로젝트를 삭제할까요?</h2>
          <button onClick={() => close(false)}>취소</button>
          <button onClick={() => close(true)}>삭제</button>
        </section>
      ),
    });

    if (confirmed) console.log('프로젝트 삭제');
  }

  return <button onClick={() => void confirmDelete()}>프로젝트 삭제</button>;
}

export function App() {
  return <ModalProvider><DeleteButton /></ModalProvider>;
}
```

Promise는 `close`를 처음 요청할 때가 아니라 닫기 모션과 제거가 끝난 뒤 처리됩니다.

## Modal과 Overlay 중 무엇을 선택할까요?

일반적인 대화상자에는 `@ilokesto/modal`을 선택하세요. 접근 가능한 이름, 포커스 트랩과 복원, 본문 스크롤 잠금, 최상단 모달만 닫는 규칙, 백드롭, 위치, 모션 감소 설정을 이미 처리합니다. 새로운 오버레이 계열을 설계하거나 이러한 정책을 직접 관리해야 할 때만 [`@ilokesto/overlay`](/ko/overlay)를 선택하세요. 알림에는 [`@ilokesto/toast`](/ko/toast)가 알맞습니다.
